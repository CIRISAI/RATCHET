## Neutral on MEANINGS, not on NAMES — declared

The mechanical principle-name substitution sits **below** the meanings partition,
so all three arms carry the substituted labels (Helpfulness, Ethics, Pluralism…)
identically. The neutral arm therefore has **alt names with neutral content**.

That is deliberate and it is the right call for the contrast this arm serves:
`form_vs_content` is `h3ere-alt − h3ere-neutral`, so matching the labels exactly
means the comparison isolates **content** and nothing else. Neutral labels would
have been more purely value-free and would have confounded content with naming.

But it is a real limit and it is stated rather than assumed: **the neutral arm is
not value-free in an absolute sense.** It is value-free *relative to the alt arm,
on the dimension the contrast measures.*
