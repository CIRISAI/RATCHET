TORQUE

Does an ethics pipeline actually hold an AI agent to the design it claims — and does it keep holding once you stop paying for it?

Status: designed, not run. No arm has been executed and there are no results. This page is the proposal: what the experiment asks, how it is built, and what would count as an answer.

The question

CIRIS agents put every decision through a pipeline — several reasoning stages and four independent conscience faculties that can veto an action. It is expensive: roughly twenty extra model calls for every single thought.

Is it doing anything?

That splits into three questions that can be answered separately, and the splitting is most of the design:

  • Does the pipeline change behaviour? Compare the agent running the pipeline against the same model handed the same values as plain instructions.
  • Do the specific values matter, or only the scaffolding? Swap CIRIS's values for a different real value system, hold everything else fixed.
  • Does it hold when you stop paying? Withdraw the pipeline mid-conversation and keep probing. If behaviour drifts back toward the bare model, the effect was maintenance, not training.

The last one gives the project its name. Torque is a force you have to keep applying. The claim under test is hold-while-paid: the pipeline holds the agent to a declared design for exactly as long as it runs. If behaviour doesn't drift back, that is a good outcome for the agent and a bad one for our explanation — and it gets reported that way.

The design

Six conditions. Four comparisons between them do the work.

ArmWhat it is
barethe model, no pipeline, no values
values-cirisCIRIS values as plain instructions, no pipeline
h3ere-cirisfull pipeline, CIRIS values
h3ere-altfull pipeline, a different real value system
h3ere-blankthe pipeline with the values removed
h3ere-nonsensevalues that look like values and rank nothing
  • h3ere-ciris − values-ciris — what the pipeline adds
  • h3ere-ciris − h3ere-alt — what the values add
  • h3ere-blank − bare — what empty scaffolding buys
  • h3ere-alt − h3ere-nonsense — whether content matters, or only value-shaped text

That last comparison is why the nonsense arm exists. Without it, a behaviour change under new values has two equally good explanations: the pipeline responds to what the values say, or it responds to there being value-shaped text in that slot at all. If nonsense moves behaviour as much as a real alternative does, the headline claim is dead whatever the effect size.

The alternative values

Anthropic's constitution for Claude (January 2026), adapted. It ranks broadly safe → broadly ethical → compliant with guidelines → genuinely helpful. CIRIS ranks from sustainable adaptive coherence. Same permitted actions, genuinely different priorities.

The choice is tightly constrained. An alternative must re-rank what the agent prioritises without changing what it is permitted to do. Anything that loosens a prohibition is not a values experiment — it is a safety experiment, and it would be refused. Claude's constitution separates absolute prohibitions from adjustable defaults, so the first can be held identical while only the second varies. It also isn't ours, which forecloses the obvious objection that we built something easy to beat.

An aside worth stating. We went looking for the most widely accepted guidance to use instead. The consensus documents — NIST's AI risk framework, ISO/IEC 42001, OWASP's agentic top ten, the Five Eyes joint guidance — are governance and security. They describe how an organisation manages risk, or what attacks to expect. None of them ranks options for an agent in the middle of a decision.

There is no widely-accepted value ordering for agents. So this is not testing CIRIS against a standard. It is testing whether any value layer does anything, in a field where none has consensus.

What gets measured

The questions come from the ETHICS benchmark — a public dataset of moral scenarios with judgements collected from human annotators. Using it means each arm is scored against an external standard that was fixed long before this project existed and cannot be tuned to the outcome.

So the measurement is not only "did behaviour change" but "did behaviour move toward or away from human judgement". A value layer that changes behaviour while moving away from human judgement is a real result, and arguably the most interesting one available.

What this cannot show. Agreement with the ETHICS annotators is agreement with a particular group of people making particular judgements. Higher agreement is not "more ethical," and this design cannot establish that it is. "CIRIS values are better than the alternative" is out of scope. "CIRIS values track this annotator pool more closely on these questions" is what the measurement carries.

Disagreement is data. Questions where the two value arms disagree with each other and with the human label are the most informative in the set, and get reported individually rather than averaged away.

How the alternative values are built

Replacing values in a normative document is harder than it sounds, because the document is mostly not values — it is procedures, thresholds, prohibitions and worked examples that must stay identical for the comparison to mean anything. Ask a writer to change one and preserve the others, and they will improve the surrounding prose, because that is what writing is.

So nothing is rewritten. The corpus is built mechanically:

  1. Split the document once, line by line, into "states a value" and "does not." Review it, then freeze it — that split is the public record of what the experiment changed.
  2. Write each changed line in isolation. The writer sees one line and the alternative source, never the surrounding document.
  3. Copy every unchanged line byte for byte. No writer sees it.
  4. Assemble and check that every unchanged line is identical. A test, not a review.

On the main document this makes the intervention 28 lines out of 1,153 — reviewed independently by two people working separately. The frozen split is published with the results, so anyone can see exactly what was varied and what was held.

Decided in advance

The design, its thresholds and the conditions under which it fails are written down and frozen before any data is collected. That includes the conditions under which we declare the whole thing void rather than report a weak result: if the instrument cannot recover a known signal planted in it, if the two value corpora cannot be matched fairly, if a measurement leaks into a condition meant to be blind to it, or if the harness cannot produce the number of questions committed to.

Two of the stakes are claims that something didn't move — that behaviour doesn't revert, or that nonsense works as well as real values. Those carry declared bounds, because "no change" is otherwise unfalsifiable: without a stated bound, any small movement can be called none after the fact.

Before the real run

A pilot of ten questions across all six arms, at about 4% of the cost. Its job is to prove the machinery works on real data — that every arm runs, that the manipulation reaches the model, that the nine-turn conversations hold up. Its outcome data is discarded and its questions are excluded from the main set, so it cannot quietly become a chance to tune the design.

The theory underneath

Two ideas carry most of the weight, at very different levels of confidence.

Effective diversity proved

With k checks correlated at ρ, you do not have k independent checks. You have

k_eff = k / (1 + ρ(k−1))

This is an identity from survey statistics (Kish, 1965). It needs no experimental validation and can receive none — computing it and comparing it against itself is arithmetic, not evidence. Machine-checked proofs are in formal/ (Lean 4).

Whether correlation predicts fragility open

The interesting claim — that measuring ρ in a real system tells you it is about to fail — is untested, here and everywhere else in our work. The bridge from a proved identity to a measured prediction has not been built, and we say so rather than letting the proof imply the prediction.

How claims are labelled

Every claim carries one of four labels, and we don't round up. "Validated" is not one of them.

LabelMeans
provedfollows deductively; no experiment can confirm or refute it
measuredobserved, with the domain stated
opentestable, not yet tested
wagerwe are betting on it, and saying so

The full grammar is in CIRISOntology. The scheme that decides which parts of a prompt may be varied — and which must be held, because varying them would change what the agent is permitted to do rather than what it values — is in the CIRIS Constitution.

Status and cost

Done: the six conditions and their comparisons; the alternative value system chosen and measured against the original; the question set fixed and its statistical power computed; the classification of every part of the agent's prompt, checked by independent reviewers; the thresholds, bounds and void conditions written down.

Remaining: finish building the alternative corpus, run the pilot, then run the campaign.

A full six-arm run is roughly 207,000 model calls — about $340, or $34 for the calibration phase that has to pass first. Cheap enough that re-running after a design change is expected rather than a setback.

Results

There are none, and there will be none here until the design is frozen, calibration passes, and the arms have run.

When they exist, every stake will be marked survives, fires or void — including the ones that go against us. A result showing the pipeline does nothing is a result, and it gets published in the same place as any other.
